## 2. 门禁 / 控制点分类标准

| 类型 | 本审计口径 |
|---|---|
| True Gate | 直接选择继续/停止、允许/拒绝、PASS/FAIL/BLOCKED 的控制点。 |
| Detector | 产生语义或事实识别结果，本身不拥有最终交付 PASS/FAIL 权。 |
| Validator | 验证 Contract、引用、Grounding、Artifact 或身份/血缘一致性。 |
| Policy Resolver | 根据输入解析要求、允许/禁止 Claim、限定语或后续动作。 |
| Derived Status | 不引入新的业务事实，把上游结果机械投影为 status/route/eligibility/review 字段。 |
| Aggregator | 对多个上游结果做全称或合并判定，产生集合或文档级结果。 |

状态性质口径：`ROOT-CAPABLE` 可首次产生失败/阻断事实；`DERIVED` 只继承上游；`AGGREGATED` 汇总多个上游；证据无法确立时标 `UNKNOWN`。

主状态链：

```text
CRAG assessment / correction route
  → prompt-visible Evidence Governance V2
  → GateDecision + generation_allowed
  → WriterGateBinding / section evidence gate
  → model output + citation grounding + Claim Audit
  → SchemeSection.status + initial formal_deliverable_eligible
  → paragraph/budget projections
  → document verification / assembly / final artifact review
  → writer integrity recomputation + evaluate_scheme_draft
  → closure checks
  → deliverable | rejected | technical_failure
  → optional explicit human approval interrupt
  → immutable release verification
```

4. **G27/G39** — Observed behavior: paragraph snapshot 可在初次 Claim Audit/formal 计算后改 content；本地不重算，最终 G39 以 hash/re-audit/formal mismatch 失败封闭。
5. **G33/G40** — Observed behavior: DocumentAssembler 的 evidence-requirement 汇总可把显式 blocked 视为 requirement satisfied；G39/G40 的 writer/formal checks 仍使这类章节不可交付。
6. **G21** — Observed behavior: Semantic Section Judge 在当前环境默认关闭；开启时 issue severity 在 G23 统一映射为 warning/PARTIAL，不直接 hard fail。

## 12. Phase 1 结论

- 当前生产 Scheme Generation 链识别出 50 个会直接或间接改变检索继续、Evidence/Writer 权限、Section status、Human Review、formal eligibility、Hard Gate、artifact route 或发布的控制点。
- Claim Audit 链已追踪到 GeneratedClaim → violations → audit.passed/review → Section FAILED → initial formal=false → G39 重算 → G40/G41 Hard Gate → rejected。
- Citation/Grounding 只把能改 status/formal/Hard Gate 的 binding support、high-risk fact、occurrence/referential/target/grounding 检查纳入总表。
- Human Review 的“交付阻断”与“顶层暂停”是两条已证实不同的控制路径。
