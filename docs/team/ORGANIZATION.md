# Organization

| 角色 | 当前职责 | 第一轮任务 |
|---|---|---|
| Project Manager | 状态、依赖、交接 | 维护 STATUS 和 TASK |
| Architect | 模块、依赖、Contract、所有权 | 汇总 As-Is 架构 |
| Agent/Workflow Engineer | Supervisor、Workflow、Agent | 还原 Query 到 UseCase |
| RAG Engineer | 检索、证据、向量库调用 | 还原在线 RAG 链 |
| Algorithm Lead | CRAG、Self-RAG、Adaptive-RAG 等 | 判断算法实际位置和启用情况 |
| Data Engineer | 清洗、Chunk、Embedding、入库 | 还原离线链 |
| QA / Reviewer | 独立核验所有声明 | 找脑补、遗漏和矛盾 |
