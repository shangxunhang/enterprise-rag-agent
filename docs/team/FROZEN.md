# docs/team Frozen Notice

## Status

`frozen`

## Effective Date

2026-07-26

## Decision

The experimental multi-role AI team workflow under `docs/team/` is paused indefinitely.

All existing task files, analyses, handoffs, reviews, policies, architecture drafts and status records are retained as historical material only.

## Rules While Frozen

1. Do not create new tasks under `docs/team/TASKS/`.
2. Do not continue TASK-001 through TASK-010 or any related remediation loop.
3. Do not treat the current `docs/team/ARCHITECTURE.md` or `docs/team/CONTRACTS.md` as approved project truth unless independently revalidated.
4. Do not update existing analysis or review documents as part of normal development.
5. Future project work should use a lightweight four-part workflow outside this frozen structure:
   - discussion/design;
   - implementation;
   - audit/review;
   - testing/verification.
6. Reactivation requires an explicit user decision and a new scope definition.

## Preservation Rationale

The directory is preserved rather than deleted because it contains useful investigation evidence, QA findings and historical reasoning that may be referenced later. Preservation does not imply endorsement or completion.
